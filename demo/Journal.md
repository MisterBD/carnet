# Journal

Une page par jour, dans le dossier `Journal/`, nommée `AAAA-MM-JJ.md`. Le menu **Journal du jour** ouvre celle d'aujourd'hui, et la crée à partir de [[Modèles/Journal]] si elle n'existe pas encore. Une tâche datée écrite ici (`📅 2026-10-13`) remonte sur l'écran **Aujourd'hui**.
