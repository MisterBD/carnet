# Achat de l'établi

Un deuxième établi, d'occasion, trouvé chez un menuisier qui partait à la retraite. Il est arrivé en pièces, il est reparti de l'atelier sous les applaudissements.

- [x] Trouver un établi
- [x] Négocier le prix (120 €, plus un café)
- [x] Le transporter sans le lâcher dans l'escalier
- [x] Le fixer au mur

> [!TIP] Ce qu'on retient
> Mesurer la porte avant d'acheter. Cette phrase est la seule vraie leçon du projet.
